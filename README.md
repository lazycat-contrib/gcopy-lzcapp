# gcopy-lzcapp

GCopy 懒猫微服应用。上游镜像已将前端嵌入 Go 程序，应用只运行一个 `llaoj/gcopy` 容器。

部署向导支持两种认证方式：

- Email/SMTP（默认）：填写 SMTP 主机、端口、用户名和密码，通过邮箱验证码登录。
- Token：开启“使用 Token 认证”后无需 SMTP，设备使用相同的 6 位 Token 登录。

LazyCat 网关负责 HTTPS，容器内部以 HTTP 监听 `3375`。应用同时注入官方文件选择器拦截器，以支持从本地设备或懒猫网盘上传、下载文件。

自动化每天检查 GCopy 单镜像稳定版本，并支持 `v*` tag 触发懒猫官方商店和喵喵私有商店发布。
